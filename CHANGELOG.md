# Changelog

## 0.1.0 (22 November 2026)

First working version as an installable web app, ported from the native Android draft.

- Profiles with optional photo, status, follow-ups, and archiving
- Custom 0 to 100 rating variables with weights, categories, and anchors; 18 defaults
- Rating history, interaction log, and per-person analysis with insights and conversation prompts
- Search, filters, and sorting
- AES-256-GCM encrypted storage, optional PIN with lockout, auto-lock, and a privacy cover
- Password-encrypted backup and restore, sent through the Android share sheet or downloaded
- Offline support and in-app update prompt
- Light and dark themes
